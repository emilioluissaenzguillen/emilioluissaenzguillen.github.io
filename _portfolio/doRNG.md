title: "doRNG: Generic Reproducible Parallel Backend for 'foreach' Loops"
excerpt: ""
collection: R
---

Functions to perform reproducible parallel foreach loops, using independent random streams as generated by L’Ecuyer’s combined multiple-recursive generator ([L’Ecuyer (1999)](https://pubsonline.informs.org/doi/10.1287/opre.47.1.159)). See [https://cran.r-project.org/package=doRNG](https://cran.r-project.org/web/packages/doRNG/index.html).
